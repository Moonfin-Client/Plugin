Smart Search

Lets Moonfin apps search with plain sentences like "90s movie about a kid pulled into a board game" or "electronic music duo from the 90s". Searches run on this server's CPU with a small model, so what people type never leaves the server. Turning it on downloads the model and indexes movies, shows, people, music and books with the Moonfin Smart Search Index task, which starts on its own with the first search. With the TMDB key on the Integrations tab it also indexes the most popular TMDB titles, so titles you don't have show up as Seerr suggestions. The first run takes 15 to 30 minutes on a desktop CPU and an hour or more on a Raspberry Pi, using half the cores. After that only changes are indexed. See the Smart Search page in the wiki.
English is the small, fast model: a 91 MB download that keeps about 120 MB in memory. Multilingual understands searches in about 100 languages and still does well in English, but it's a 488 MB download, keeps about 175 MB in memory, and its first build takes about two and a half times as long. After that, nightly updates only index what changed and searches are about as fast with either model. Changing this rebuilds the index, which starts with the next search.

How custom labels match
A custom label shows when all its conditions hold. Any, No and Every say which tracks of that type a condition looks at: at least one, none of them, or all of them. A file without such a track never passes Every. For the file path and the track counts, Unless turns the test around. Each condition is checked on its own, so two conditions on audio can be met by two different tracks.

Text tests ignore case. Is one of takes a list separated by commas, such as fre, fra. Matches pattern takes a regular expression. Labels with the same text are alternatives: the label shows once if any of them holds. Track values are the ones in Jellyfin's Media Info for the file.
